# 📊 LA Metro Gentrification Risk Modeling

## Predicting Gentrification Risk Near the D Line Extension

## Project Overview

This applied data science project examines potential gentrification risk in neighborhoods near the LA Metro D Line Extension.

The project uses economic and demographic indicators to explore how neighborhood characteristics may be associated with gentrification risk and to compare several statistical and machine learning approaches.

## Research Question

**Can economic and demographic indicators be used to identify neighborhoods that may be at greater risk of gentrification near the LA Metro D Line Extension?**

## Variables Examined

The analysis considered:

- Rent
- Rent burden
- Rent growth
- Price per square foot
- Changes in educational attainment
- Geographic proximity to transit

## Statistical & Machine Learning Methods

The project compared several modeling approaches:

- Ordinary Least Squares (OLS)
- Ridge Regression
- Random Forest
- XGBoost

## Project Highlights

- Combined multiple economic and neighborhood indicators for analysis.
- Examined relationships between housing and demographic variables and potential gentrification risk.
- Compared traditional regression with machine learning methods.
- Evaluated model performance across different approaches.
- Conducted additional analysis using multiple LA Metro lines to examine the robustness of the results.
- Translated statistical results into findings that could support data-informed decision-making.

## Tools & Skills

**Methods:** OLS, Ridge Regression, Random Forest, XGBoost  
**Skills:** Predictive Modeling, Regression, Machine Learning, Data Analysis, Model Comparison, Data Visualization

This project demonstrates how statistical modeling and machine learning can be applied to a complex real-world problem involving transportation, housing, and neighborhood change.
